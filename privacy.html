MEN'S RISE 個人カルテ作成ツール

プライバシーポリシー

最終更新日：2026年8月30日

1. このツールについて

「Men's Rise 個人カルテ作成ツール」（以下「本ツール」）は、Men's Rise の受講生向け個人カルテを作成するために、社内の担当者が使う業務用ツールです。一般の方に向けて提供しているサービスではありません。

2. 取り扱う情報

本ツールは、カルテの作成に必要な次の情報を取り扱います。

  • 受講生の氏名・呼び名・受講生ID
  • カウンセリングおよび月次フォームの回答内容（体重・体脂肪率・生活習慣など）
  • 受講生から提出された写真（顔・全身・身体）
  • 作成したカルテと、その作成履歴（監査ログ）

3. 情報の保存場所

本ツールはサーバーを持ちません。読み込んだデータと写真の加工は、すべて担当者のパソコンのブラウザの中だけで行われ、当社や第三者のサーバーへ送信されることはありません。

担当者がGoogleドライブとの接続を有効にした場合に限り、作成したカルテと写真が、担当者がログインしたGoogleアカウントのドライブに保存されます。保存先は本ツールが作る専用フォルダと、担当者自身が明示的に選んだフォルダだけです。

4. Googleアカウントへのアクセスについて

本ツールがGoogleに求める権限は次の2つです。

  • drive.file（作成・変更）— 本ツールが作成したファイル（カルテ・写真）にのみ、書き込み・変更ができます。
  • drive.readonly（読み取り）— 受講生が月次フォームで送信した写真を取り込むために使用します。読み取り専用であり、この権限でファイルを変更・削除することはできません。

本ツールが読み取るのは、担当者が設定したフォームの写真フォルダと、本ツール自身が作成したファイルのみです。読み取った写真は担当者のパソコンのブラウザ内でのみ処理され、当社や第三者のサーバーへ送信されることはありません。

本ツールが Google API から取得した情報は、カルテの作成・保存という本ツールの機能を提供する目的にのみ使用します。広告目的での利用、第三者への販売・提供、人による内容の閲覧（法令に基づく場合、セキュリティ上必要な場合、利用者の明示的な同意がある場合を除く）は行いません。本ツールによる Google ユーザーデータの取り扱いは、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. 第三者への提供

受講生の情報および写真を、本人の同意なく第三者へ提供・公開することはありません。

6. 保存期間と削除

カルテおよび写真は、サービス提供に必要な期間保存します。受講生ご本人から削除のご希望があった場合は、公式LINEよりご連絡いただければ速やかに削除します。
